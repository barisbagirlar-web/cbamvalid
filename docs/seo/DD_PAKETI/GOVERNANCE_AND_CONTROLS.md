# Governance and Controls

SEO V6 is governed by the repository mandate, site config, phase write contracts and 127-invariant registry.

Core controls include: canonical/redirect integrity; sitemap/robots parity; rendered-content parity; content similarity/privacy review; schema evidence/entity dedupe; internal-link and CWV gates; verified bot identity; integer-money P&L discipline; crisis/migration runbooks; cluster ownership and portfolio approval chains; SRE issue escalation; off-page link-scheme prohibition; CRO experiment locks; vertical-module guards; TAM evidence discipline; portfolio-economics approval; and fail-closed programmatic eligibility/rollback.

BLOCK invariants require executable negative fixtures before a phase is marked completed. Runtime deployment is separate from merge and is prohibited when runtime output did not change.
