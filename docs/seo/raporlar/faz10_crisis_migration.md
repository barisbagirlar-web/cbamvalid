# Faz 10 — Crisis / Migration Controls

- Migration requires exact tested/merged SHA, rollback SHA and explicit human approval where external/irreversible controls are involved.
- Four required crisis cards are defined: organic visibility decline, manual action, technical discovery/indexing failure, and organic value/conversion crisis.
- Each card has detection evidence, first-four-hours controls, decision path and communication template.
- PR-level executable diff scan rejects destructive shortcuts plus automatic 301/publication, bulk 410, HSTS preload, paid-link/PBN/cross-site schemes, fake lastmod, hidden schema claims, fabricated FAQ and ranking-guarantee controls.
- Annual non-production drill procedure exists; no completed drill evidence is available, so INV-10.3 remains `SKIP_NO_DATA` rather than inventing a date/result.
- Runtime application files are unchanged; deploy is not required.
