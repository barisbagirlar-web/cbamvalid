# Faz 10 — Crisis / Migration Controls

- Migration requires exact tested/merged SHA, rollback SHA and explicit human approval where external/irreversible controls are involved.
- Runbook prohibits unsafe shortcuts such as force-pushing main, auto-merge and destructive project deletion.
- SEO incident response freezes unrelated releases, captures evidence first and prefers known-good rollback over broad emergency rewrites.
- Annual non-production drill procedure exists.
- No completed annual drill evidence is available, so INV-10.3 remains `SKIP_NO_DATA` rather than inventing a date/result.
- Runtime application files are unchanged; deploy is not required.
